      \begin{itemize}
        \item \textbf{Survivorship}: usually only accepted papers are visible\\
          $\to$ \alert{all submissions: accepted, rejected, withdrawn}
        \item \textbf{Hindsight}: topics defined with today's eyes\\
          $\to$ \alert{early-year topic maps}
        \item \textbf{Forking paths}: many ways to analyse\\
          $\to$ \alert{pre-registration, one frozen run}
      \end{itemize}
    \end{column}

% ---------------------------------------------------------------- 6. C2 design
\begin{frame}{Contribution 2: a design that keeps us from fooling ourselves}
  \centering
  \begin{tikzpicture}[node distance=0.28cm]
    \node[pbox] (a) {\textbf{Register}\\hypotheses and decision rule};
    \node[pbox,right=of a] (b) {\textbf{Build}\\all variables blind to acceptance};
    \node[pbox,right=of b] (c) {\textbf{Simulate}\\12,400 runs on fake data to test the pipeline};
    \node[pbox,right=of c] (d) {\textbf{Freeze}\\code and inputs (hashes)};
    \node[pbox,right=of d,fill=corange!8,draw=corange!60] (e) {\textbf{Run once}\\report every result};
    \foreach \x/\y in {a/b,b/c,c/d,d/e} \draw[arr] (\x) -- (\y);
  \end{tikzpicture}

  \vspace{1em}
  \begin{columns}[T]
    \begin{column}{0.48\textwidth}
      \small\textbf{A claim needs all four:}
      \begin{enumerate}
        \item the predicted direction
        \item corrected $p < 0.05$ (Holm)
        \item the same direction in ${\geq}75\%$ of the alternative analyses (9--11 per question)
        \item the same direction on both hindsight-check maps
      \end{enumerate}
    \end{column}
    \begin{column}{0.48\textwidth}
      \small\textbf{The simulation caught a real problem}\\[0.3em]
      In a realistic no-effect scenario, standard clustered errors gave up to \alert{12.6\%} false positives where
      5\% was promised. So the newcomer results get two extra checks.
    \end{column}
  \end{columns}
\end{frame}

      \end{block}
    \end{column}
  \end{columns}
  \vspace{1em}
  \take{Fashion spreads, but the review process does not visibly reward following it.}
  {\footnotesize\muted{What does go with acceptance (associations, not advice): theory papers ($+9$\pp{} vs.\ new
  methods), larger teams. See backup.}}
\end{frame}

% ---------------------------------------------------------------- 11. contributions
\begin{frame}{Contributions}
  \begin{enumerate}
    \item \textbf{A measurement warning, with a fix.} Topic maps fitted in hindsight invent ``emerging''
      topics and can flip trend conclusions. Early-year maps are a cheap check.
    \item \textbf{A rigorous template for science-of-science.} Pre-registered, outcome-blind,
      simulation-checked, one frozen run.
    \item \textbf{New evidence on research fashions.}
      \begin{itemize}
        \item where foundation models spread, new architectures fade (pre-registered)
        \item newcomer papers lean to new methods, not to following (opposite to our prediction)
        \item style spreads like topics, without a reward (exploratory)
      \end{itemize}
  \end{enumerate}
  \vspace{0.4em}
  {\small\muted{Limits: one venue; associations, not causes; labels from an LLM ($\kappa = 0.93$, not yet checked by
  humans); author IDs changed in 2021, so some incumbents look like newcomers (expected to push estimates towards
  zero).}}
\end{frame}

\begin{frame}{B3. Why we did not trust standard errors}
  \small
  \begin{itemize}
    \item Before seeing any result, we ran 12,400 simulations, including scenarios with \textbf{no true effect}
      but realistic topic structure.
    \item When the true topic structure cuts across our 100 topics, the standard test rejected \alert{12.6\%} (method) and
      10.0\% (benchmark) of the time, not 5\%. A wild bootstrap did not fix it.
    \item So we added, before the run:
      \begin{itemize}
        \item two-way clustering (two different topic maps at once);
        \item a stress test: shrink each $t$-statistic by the inflation seen in simulation (1.31 / 1.22).
      \end{itemize}
    \item Newcomer results: $t = 6.7$ and $-4.4$. After the stress test, Holm $p$ = $4\times10^{-6}$ and $10^{-3}$.
  \end{itemize}
  \vspace{0.3em}
  \take{Lesson: check your test on data shaped like yours before trusting its $p$-values.}
\end{frame}

\begin{frame}{B11. Definitions}
  \small
  \begin{description}[Topic maturity]
    \item[Topic] one of 100 clusters of paper embeddings (title + abstract)
    \item[Topic maturity] $\log(1 + \text{earlier papers in the topic})$; $+1$ = 2.7$\times$ more papers
    \item[Hot topic] top fifth of topics by last year's growth
    \item[Newcomer paper] no author has an earlier ICLR submission (any outcome) in that topic
    \item[FM adoption] share of the topic's papers last year that built on a foundation model
    \item[Benchmark \& eval.] primary contribution is a dataset, benchmark or evaluation
    \item[Model] linear probability model with topic and year fixed effects (topic $\times$ year cells for the
      newcomer comparisons); errors clustered by topic
    \item[pp] percentage points
  \end{description}
\end{frame}
